# HITS Chatbot Monorepository

This monorepository is involved with the overall developement of the chatbot, from the extraction and embedding of relevant documents inside of a VectorDB to the API backend that exposes its functions as a service.

To setup the environment make sure to have [uv](https://docs.astral.sh/uv/) installed in your system, and run the command:

```uv sync --all-packages```

from the root directory of the repository.
